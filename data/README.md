# Data folder

Keep downloaded/source data separate from processed/model-ready data.

- raw/: source copies, preserved unchanged when permitted.
- processed/: validated data aligned to the fiscal-quarter key.
- Document source URL, publication date, retrieval date, units, period, definitions and any revisions.

Do not commit personal data, access credentials, or raw files unless the source's redistribution terms permit it. When rights are unclear, keep data local and link to the original source instead. The final historical coverage and usable row count will be established in D2.
