# Model artifacts

The selected model is not available yet. Do not commit an unvalidated model artifact.

When a model is evaluated and approved for the prototype, document:
- model/version identifier and training period;
- target and exact feature set;
- preprocessing and missing-value treatment;
- chronological split / rolling-origin design;
- MAE, RMSE, baseline comparison and limitations;
- forecast-date availability and reproducibility notes.

Local binary model artifacts are ignored by Git by default. Decide how to store a reviewed artifact after the model-development stage.
